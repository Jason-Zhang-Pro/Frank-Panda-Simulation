# 接触后恒力保持

接触前沿用半开口参考每秒 0.02 m 的缓慢闭合与位置 PD。控制节点订阅 /target_contacts，只接受 target_cube 与左右手指的仿真时间接触消息。双侧接触在最近 0.15 秒内出现并持续确认 0.08 秒后，锁存恒力保持模式，以每秒 25 N 的变化率转向每指 -10 N 指令。两个手指正方向都是张开，因此负力为向内夹紧。

这是关节恒力指令，不是接触力反馈闭环；不会保证每个实际接触法向力恒等于 10 N，也不建立固定约束。锁存后短暂接触消息缺失不退出，仍保持向内力以尝试恢复接触；抓放状态机保留原有实际接触及抬升检查。张开指令立即退出恒力模式并恢复位置控制。仿真时间回退、无效关节反馈或有效反馈超时会清除接触确认与恒力锁存，需重新确认接触。暂停时保留上一控制输出。

controller.yaml 参数：gripper_close_kp=400 N/m，gripper_close_force_limit=10 N，gripper_hold_force=10 N。参数启动时读取，hold_force 不得超过闭合限幅，两指模型 effort 上限同步为 10 N。摩擦参数不在此次修改范围内。

```bash
ros2 topic echo /gripper_status --qos-durability transient_local
```

状态包括 closing、force_hold、position。未收到双指接触时一直采用位置闭合，不能仅凭关节停止运动认定夹住。必须启动现有 /target_contacts 桥接。本次五算法实验已采用该控制与柔顺指垫配置；修改后需重启Gazebo加载模型与控制节点。

## 双指中心稳定

恒力模式同时稳定夹口中点 c=(q_left-q_right)/2，目标 c=0。以 200 N/m 比例和 4 N·s/m 差速反馈生成左右差动力，幅度不超过夹持目标力的 40%。这些增益仅作用于两根手指，不改动七轴手臂 PD、URDF 关节阻尼或轨迹。

当目标夹持力已等于每指 10 N 上限时，没有继续增加单侧力的余量。因此偏心时降低另一侧力来产生净回中作用，而不是突破限值。例：左指 40 mm、右指 20 mm 且速度为零，目标指令为左 -10 N、右 -6 N；居中静止后恢复两侧各 -10 N。差动力限幅后两侧目标始终向内，最低为目标力的 20%，并沿用每秒 25 N 的平滑过渡。

每秒日志记录夹口中心偏差、差动力及双指指令。它测量的是双指几何中点，不是方块质心；摩擦、外力和限幅可能导致稳态偏差，本次任务记录见五算法报告，但尚无连续滑移或接触力的定量标定。仍不属于接触力闭环。
