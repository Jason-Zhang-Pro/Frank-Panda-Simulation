# Gazebo 30 秒预算原始记录

RRT / RRT-Connect / RRT* 各运行种子 1、2、3，每个全局搜索请求预算 30 秒；有效任务共 9 次。所有原始任务尝试保留，不按结果挑选。

`raw/` 保存运行日志、状态事件和任务 CSV，`trials.csv` 合并任务数据，`phases.csv` 从日志提取各阶段搜索和轨迹指标，`summary.csv` 汇总同类接近段和成功计数。失败任务的累计长度只表示任务前缀；位置与路径长度均来自实际消息和轨迹，不是手填。

机器人、world URDF/SDF、PD 配置内容经 SHA-256 核对与 5 秒组一致；`source_sha256.txt` 记录实现文件指纹。该组仅通过启动参数调整搜索预算，日常默认值未改。整套任务上限仍为 240 秒，采集器上限 270 秒。

原有仿真保留运行，测试独立 ROS 域和 Gazebo 分区，每次冷启动物理世界。物理反馈并非确定性回放，种子相同不代表状态轨迹完全相同。环境快照、批处理日志和域分配均已保存。

任务成功需收到 `pick_place_succeeded`；生成路径成功不是完整任务成功。`plan_success` 是生成且复检通过的轨迹，`execution_arrived` 是实际收到该段到位状态。首解时间受回调和日志精度限制。空字段不当作零。

本组没有额外记录的启动失败。
