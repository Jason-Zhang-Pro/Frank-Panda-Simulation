# 抓放时间优化原始记录

RRT-Connect / 30 秒搜索预算 / 种子 1、2、3。只启用新的抓放时间分配，PD、速度与加速度配置、接触及到位判定不改。对照为此前 30 秒组的保守时间实现；本组不是三算法重跑，不能混入原算法比较统计。

`timing.csv` 从每段日志提取同一候选 B 样条的旧保守估计和优化时长；`trials.csv` 是真实任务终止记录；`phases.csv` 是阶段信息；raw 目录保留日志与事件。失败试验长度仅累计任务前缀。

限速与加速度由最终控制 Hermite 多项式的 Bernstein 包络复检，碰撞仍离散采样。没有测量 jerk 或振荡 RMS，也未把参考轨迹更快当作物理稳定性证明。

另有任务提交前的控制器列表服务超时，已保留启动日志并换隔离域重试；没有删除已提交的失败任务。Gazebo 退出阶段报错也保留在原始日志中。
