# 下一步：A* 与可重复比较

A* 为下一阶段研究方向，当前尚未实现。

1. 先选择搜索空间。2D/3D 栅格 A* 可用于理解搜索与可视化，但只规划末端位置无法保证 Panda 全身避障；直接离散七维关节空间会面临巨大的状态数。
2. 给出状态分辨率、邻接动作、边代价和启发函数。关节欧氏长度作代价时，欧氏距离可作启发的起点，但要与具体边代价和周期角处理匹配。
3. 复用当前 URDF 限位及 FCL 状态/边检查，避免算法之间碰撞模型不一致。先用低维小问题验证，再扩展机械臂任务。
4. 使用相同有效起终点、环境、预算和后处理，比较成功率、墙钟时间、内存、节点扩展数及路径长度；采样算法跨种子重复。
5. 再研究时间参数化的保守性、抓放接触控制、携物重力补偿与控制周期测量。A* 不会自动解决轨迹平滑或 PD 振荡。
