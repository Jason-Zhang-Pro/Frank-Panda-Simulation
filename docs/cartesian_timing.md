# 抓放 B 样条时间分配优化

## 改动

保留几何 B 样条、IK 路点、直线/姿态容差、速度比例 0.3、加速度上限 0.9 rad/s²、PD、接触判定和到位阈值。只优化抓放直线段的全段时间缩放；全局搬运和归位仍采用原保守时间分配。

旧方法把曲线一阶/二阶导数的全局最大值，与时间函数导数的全局最大值组合；这些峰值不一定发生在同一时刻，容易过度减速。新方法先采样组合后的实际相位导数，估计较紧的时长，再对发送给控制器的每段五次 Hermite 插值计算 Bernstein 包络，复检速度与加速度。若超限，增大时长并重建轨迹；最后可恢复旧时长。采样只是估计，不是限速证明；最终判定依据实际插值包络。

本版保留 10% 估计余量，并将提速限制为同一候选曲线原保守时长的最多 2 倍。随后仍执行原位置包络、离散碰撞及 TCP 直线/姿态复检。碰撞仍是离散检测，不是连续安全证明；没有新增 jerk 限制。

## Gazebo 验证

固定 RRT-Connect、搜索预算 30 秒、种子 1/2/3，在独立世界中执行三个完整任务尝试。对照为已发布的 30 秒组原保守实现；模型、场景和 PD 快照相同。物理状态并非逐采样确定性回放，不把成功次数变化解释为已修复接触稳定性。

| 种子 | 旧实现完整任务 | 新实现完整任务 | 新实现终止墙钟 / s | 新结果 |
|---|---:|---:|---:|---|
| 1 | 失败 | 成功 | 114.28 | pick_place_succeeded: 真实抓取、放置、松开和避障归位全部完成 |
| 2 | 成功 | 成功 | 102.90 | pick_place_succeeded: 真实抓取、放置、松开和避障归位全部完成 |
| 3 | 失败 | 成功 | 90.34 | pick_place_succeeded: 真实抓取、放置、松开和避障归位全部完成 |

本次新实现完整成功 **3/3**，旧组为 1/3。样本很小，终止时间包含失败前缀，不能直接当作完整周期效率排名。全局路径也可能随实际姿态与采样改变。

## 使用

默认启用 `cartesian_timing=bounded`。恢复旧算法无需改 PD：

```bash
./start.sh cartesian_timing:=conservative
# 或对运行中的规划器设置，下一次规划生效：
ros2 param set /panda_ompl_planner cartesian_timing conservative
ros2 param set /panda_ompl_planner cartesian_timing bounded
```

复现本次验证：

```bash
ALGORITHMS=rrt_connect CARTESIAN_TIMING=bounded RUNS=3 TIMEOUT=30.0 \
  BENCHMARK_ROS_DOMAIN_ID=160 BENCHMARK_IGN_PARTITION=panda_timing \
  ./tools/compare_gazebo.sh
```

[逐任务数据](results/cartesian_timing_2026-10-25/trials.csv) · [逐阶段](results/cartesian_timing_2026-10-25/phases.csv) · [时长对照](results/cartesian_timing_2026-10-25/timing.csv) · [原始记录](results/cartesian_timing_2026-10-25/README.md)

本方法不是时间最优参数化，也没有采用逐段局部加速规划；当前仍是一条曲线的全段时间缩放，优先减少旧最坏上界的保守性。

本组另有 2 次任务提交前的启动服务超时，原始日志已保留并换隔离域重试；它们不计入三个有效任务，也未重跑任何已提交的失败任务。
