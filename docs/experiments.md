# 规划与抓放的实现及实验记录

## 路径与轨迹

接入OMPL的RRT、RRT-Connect和RRT*，并实现七维网格A*及惰性PRM＋A*。所有算法使用同一套MoveIt/FCL碰撞场景和携物模型。候选路径经无碰撞远端shortcut简化，再生成B样条轨迹与时间分配，复检控制端实际Hermite插值的碰撞和速度／加速度约束。

抓放直线段采用局部IK与约束B样条，避免关节空间平滑破坏末端直线和姿态约束。曾尝试在线雅可比速度控制；当前采用的预规划轨迹跟踪效果更适合该抓放任务，实验方案保留但不默认启用。

## 夹持滑移修复

针对方块相对夹爪滑动、转动，引入双指接触确认后的夹持力保持和夹口中心稳定。单纯增加夹持力未充分解决接触稳定性，因此进一步将每侧指垫划分为四个带弹簧阻尼的被动接触片，近似橡胶的局部压缩与贴合。七轴控制增益和关节阻尼保持独立，方块没有焊接或瞬移。

已解决夹爪搬运方块时的滑动问题。本次15次任务没有接触丢失、放置位置或实际到位失败，未完成均为搜索失败；

## 场景一致性

修复台座穿过桌板、挡板与抓取台重叠、料箱墙角及货架连接处交叠，并调整右侧立柱位置。同步修改SDF与URDF，检查旋转后的包围盒无静态体积重叠；保持抓取及放置工作面高度。原复杂场景与独立桌面场景分别保留。

## 五算法统一实验

统一world场景、柔顺指垫、控制配置、shortcut和B样条，每种算法三个种子，共15次新任务，每次全局搜索预算30秒。按种子交错运行独立无GUI世界，失败全部保留，PRM建图与查询分开记录。

完整任务成功：RRT 1/3、RRT-Connect 3/3、RRT* 0/3、A* 0/3、PRM＋A* 3/3。PRM成功任务平均墙钟86.65秒，RRT-Connect为110.61秒；PRM初始接近均直接连接通过，任务时长差异还包含归位轨迹时长，不能全部称为搜索加速。
